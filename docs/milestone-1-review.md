# Milestone 1 Runtime Vertical Slice Review

## Status

Milestone 1 completed on 2026-08-30. A project generated by `gridthorn new`
builds and runs a controllable sprite through the public SDK facade.

## Validated workflow

```console
cargo run -p gridthorn_cli -- new ../hello-gridthorn --engine-path ./crates/gridthorn
cargo run -p gridthorn_cli -- check ../hello-gridthorn
cargo run -p gridthorn_cli -- run ../hello-gridthorn
```

The generated game opens a native window. WASD or arrow keys move the sprite,
Space resets it, and Escape exits. A screen-space overlay visualizes host-frame
duration, fixed work, accumulated lag, and overload. Automated verification
runs the generated project with `--smoke`, executing the same world and
schedule composition without requiring a graphical CI desktop.

## Evidence

- The CLI lifecycle test generates a fresh project, validates both manifests,
  compiles it, and executes its smoke path.
- Domain tests cover lifecycle ordering, fixed-time accumulation and overload,
  input edges, world access, presentation extraction, asset decoding, sprite
  geometry, and surface lifecycle behavior.
- The repository verification runs formatting, workspace checks, Clippy,
  tests, documentation tests, and dependency-boundary enforcement.
- The `runtime-input` example additionally exercises native input, textured GPU
  presentation, timing overlay rendering, and automatic window shutdown.

## Deliberate limitations and deferrals

- Public runtime APIs remain provisional before `1.0.0`.
- The renderer supports one orthographic camera and axis-aligned sprites;
  batching, animation, layers, and richer materials belong to Milestone 2.
- Decoded textures are uploaded for presentation without a persistent GPU
  cache. Asset dependency tracking and hot reload belong to Milestone 2.
- The timing overlay is a compact bar visualization without text or historical
  graphs. Full profiling belongs to Milestone 4.
- Runtime performance and distributable binary-size targets are deferred until
  representative Milestone 2 game content exists. CI continues to monitor
  build correctness on Windows, Linux, and macOS.
