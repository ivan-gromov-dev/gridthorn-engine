# Font fixtures

Unmodified Noto Sans Regular and Noto Sans Arabic Regular from
https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf, licensed under the
SIL Open Font License in OFL.txt.

Unmodified Noto Sans JP Regular from
https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/JP, licensed under
the SIL Open Font License in OFL-CJK.txt.

These files are test fixtures only; the engine does not embed or discover fonts
at runtime. They cover Latin/Cyrillic/combining marks, Arabic contextual shaping
and bidi, and Japanese fallback without dependence on the host font installation.
